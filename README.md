Назначение проекта:
Учебный сквозной проект по дисциплине «Объектно-ориентированное проектирование». Проект выполняется в течение семестра и проходит этапы формулировки требований, построения UML-диаграмм, проектирования архитектуры и реализации прототипа.

Предметная область:
Библиотечное обслуживание: учёт фонда изданий, обслуживание читателей, бронирование, выдача и возврат экземпляров, начисление штрафов за просрочку, уведомление читателей о сроках.

Правила работы с репозиторием:

Ветка main хранит согласованные артефакты, готовые к сдаче.

Текущая работа ведётся в ветках docs/lrN и feature/название.

Прямая запись в main запрещена.

Изменения принимаются через Pull Request после просмотра минимум одним членом команды.

Commit-сообщения оформляются с префиксом лабораторной работы, например: [LR1] добавлена таблица требований.

Правила именования файлов:
Отчёты: LR<N>КомандаN_ЧитЗал.pdf
Промежуточные документы: <дата><тема>_v<версия>.<расширение>
Идентификаторы в коде — на английском, документация и требования — на русском.
Идентификаторы требований FR-01–FR-15 не переименовываются на последующих лабораторных работах.

Структура репозитория:
docs — отчёты лабораторных работ и рабочие материалы
docs/requirements — таблица функциональных требований и словарь терминов
docs/diagrams — схемы бизнес-процессов AS-IS и TO-BE, UML-диаграммы
src — исходный код (появляется с лабораторных работ № 3–4)

Ответственный за актуальность репозитория на текущем шаге: разработчик интерфейса и данных.
